# HQ Coleção 🚀

Uma plataforma web para colecionadores de quadrinhos (HQs) organizarem, exibirem e compartilharem suas coleções de forma simples, visual e social.

---

## 🧠 Visão do Produto

Criar a plataforma definitiva para colecionadores de HQs, onde qualquer pessoa possa registrar, exibir, organizar, explorar e compartilhar sua coleção de quadrinhos com uma experiência personalizada e fácil de usar.

---

## 🎯 Público-Alvo

- Colecionadores amadores e profissionais de HQs
- Leitores casuais que querem controlar suas leituras
- Lojistas e sebos que desejam expor acervos
- Comunidades e influenciadores do nicho geek/nerd

---

## 💡 Funcionalidades principais (MVP)

- Cadastro e login (e-mail e Google)
- Buscar HQs via API externa (ComicVine)
- Adicionar HQs à coleção, editar status e avaliações
- Visualizar coleção em formato de prateleira digital
- Remover HQs da coleção
- Compartilhar coleção com link público
- Seguir outros colecionadores e curtir coleções
- Navegação entre páginas com React Router

---

## 🛠️ Tecnologias utilizadas

- Frontend: React, React Router DOM, CSS
- Backend: Node.js, Express.js, SQLite (local)
- API externa: ComicVine API
- Ferramentas: Postman para testes, Git para versionamento
